# Contate-nos-Pet-Shop-AuMiaus
Projeto de prática Full Stack: Formulário de contato para o PetShop AuMiaus. Este projeto foi desenvolvido como parte dos estudos no curso TI do zero ao pro. Os dados do formulário são enviados para uma API fictícia via Fetch API (método POST), com objetivo didático. Não há integração com um back-end real.
